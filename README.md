# CareLend Portal MVP

Clickable demo of the CareLend (Droga Health SACCO) admin portal MVP, built from the "CareLend Portal — MVP" Claude Design canvas.

- `index.html` — a small renderer that runs the canvas screens as a plain website
- `screens.json` — every screen of the canvas (82)
- `assets/` — logos and sample images
- `vercel.json` — sends every page address to `index.html`

No build step. Vercel serves the folder as static files. `/demo` opens the Demo guide.
